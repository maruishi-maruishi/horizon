# 古いバージョンのクライアントを入れる（1.21〜26.2）

自分用サーバーで、バニラの 1.21.1〜26.2 のクライアントが 26.3 の Horizon サーバーに入れるようにする仕組みです（ViaBackwards と同じ役割）。本家の `horizon-protocol` の `client_session`（古いクライアント向けの変換）を土台に、足りない部分を足しています。ViaVersion／ViaBackwards のコードは使っていません（GPL のため）。

## 決めたこと（2026-11-12）

| 項目 | 決定 |
| --- | --- |
| 対象 | 1.21〜26.2（1.21.1, 1.21.3, 1.21.4, 1.21.5, 1.21.6, 1.21.8, 1.21.10, 1.21.11, 26.1.2, 26.2 で確認） |
| 古いバージョンにない物 | 近い物で代用し、アイテムには「26.3: ○○」という灰色の説明を付ける |
| 目標 | 普通に遊べる（入る、歩く、壊す・置く、インベントリとチェスト、チャット、コマンド、モブ、死亡と復活、ネザー移動） |
| 対象外 | 進捗、レシピ本（1.21.11 以前は空）、地図、本、看板の編集の細部 |

## 使い方

1. 古いバージョンのデータを用意する（一度だけ）。各バージョンの公式クライアント jar から、そのバージョンが持っているデータの一覧を取り出します。出力は Mojang のデータなので、リポジトリには入れず `resources` フォルダにだけ置きます。

   ```sh
   python -I tools/prepare_older_clients.py <サーバーの resources フォルダ> <1.21.1.jar> <1.21.3.jar> ... <26.2.jar>
   ```

   `resources/older/<プロトコル番号>.json` ができます。用意していないバージョンのクライアントは、従来どおり 26.3 のデータを受け取ります（ほぼ入れません）。

2. `server.properties` に次を書く。

   ```properties
   horizon-accept-older-clients=true
   ```

## 仕組み

- **ワールド情報（レジストリ）**: そのバージョンのクライアントが自分で持っているデータは、バニラの「既知のパック」の仕組みでクライアント自身のものを使わせます。26.3 にしかない項目（新しいバイオームなど）は、そのバージョンで通用する代わりのデータを本来の名前で送ります。サーバー側の番号はそのまま使えます。そのバージョンにないレジストリは送りません。
- **タグ**: そのバージョンの組み込みデータが使うタグ（例: 1.21.10 の `enchantable/sword`）が 26.3 にないときは、そのバージョンのタグファイルから作って足します。ないレジストリのタグは送りません。
- **コマンド**: そのバージョンにないレジストリを使う引数は、文字列としてクライアントに送ります（中身はサーバーが確かめます）。
- **エンティティ**: データの種類番号を各バージョンの並びに直します。そのバージョンにないエンティティは代わりのエンティティで表示し、元のデータは送りません。
- **アイテム**: 代用したアイテムには、説明の1行目に「26.3: ○○」を付けます。チャットのアイテム表示（ホバー）も代わりのアイテムにします。
- **レシピ**: 表示できない結果のレシピは送りません。1.21.11 以前にはレシピ本を送りません（作業台で作ることはできます）。
- **動き**: 古いクライアントがテレポートの確認と一緒に送る移動や、1.21.3 以前の「ティックの終わり」がない動きで、サーバーが切断しないようにしています。

## 確認したこと（2026-11-12）

各バージョンの本物のクライアント（Mojang 公式の jar、オフライン名）を自動で起動してサーバーに入れ、コマンドで次を送って、切断や通信エラーがないことを確かめました。

アイテム（26.3 の新アイテム、エンチャント本、ポーション、花火、地図を含む）、防具と盾、チェスト、ブロック設置、モブ（ゾンビ、牛、オオカミ、猫、羊、村人、防具立て、表示エンティティ、26.3 のクッション、雷）、パーティクル、音、経験値、効果、ダメージと死亡、ネザーとエンドへの移動、ゲームモードの変更、タイトル、ボスバー、スコアボード、個人メッセージ。

## 分かっている制限

- 飾り壺の模様は、26.2 以前では無地に見えます（データの形が変わったため。切断はしません）。
- 1.21.11 以前ではレシピ本が空です。
- クライアントの操作（実際に歩く、掘る、クリックする）は、自動テストでは試せていません。最後に自分のクライアントで確かめてください。
- 1.20.5／1.20.6 も入れる設定になっていますが、確かめていません。
